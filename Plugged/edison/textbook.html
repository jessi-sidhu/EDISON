1.4 Inverting Op-Amp with Negative Feedback

In the inverting amplifier of Figure 1.1, the input drives the op-amp's − input through R1, and R2 feeds the output back to that same input. The + input is tied to ground.

Treat the op-amp as ideal: its inputs draw no current, and with negative feedback the output moves until both inputs sit at the same voltage. The − input is therefore held at 0 V, a virtual ground. The current Vin/R1 cannot enter the op-amp, so all of it flows on through R2, and Vout must sit below ground by R2 × Vin/R1.

The gain, A, is set by the two resistors alone. Drag any dotted value to change it.

1.5 Non-Inverting Amplifier

In Figure 1.2 the input and ground trade places: Vin drives the + input, and R1 runs from the − input to ground. Negative feedback holds the − input at Vin, so a current Vin/R1 flows down through R1. None of it enters the op-amp, so it must come from the output through R2, which lifts Vout above Vin. The gain is positive and never below 1.

The gain again depends only on the resistor ratio:

A=1+R2R1=1+10 kΩ10 kΩ=2
