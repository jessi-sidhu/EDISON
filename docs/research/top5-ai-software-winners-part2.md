# Serious software-only AI winners, part 2: TreeHacks 2026 and UC Berkeley AI Project 2026

Research date: 2026-09-26. Source: `2026-winners-us-west-midwest.md` (TreeHacks section and UC Berkeley AI Project section). Prize lists were re-checked against every winner's Devpost page (the "Winner" list on each project page), and ambiguous projects were re-read on Devpost.

**Filter:** kept only projects where (1) an LLM, AI model or agents are load-bearing in the product, (2) it runs on a normal laptop, phone, tablet or webcam, and (3) it is a serious product. Prize counts are the number of Devpost winner badges (a Berkeley "Finalist" badge counts as one). Placements are given only when a source states them; Devpost usually does not.

**Totals:** TreeHacks: 46 kept of 64 winners. Berkeley: 45 kept of 54 winners. Combined: 91 kept of 118.

## Tagging and filter notes

- **Borderline keeps:** ChromaChord needs a standard MIDI keyboard (a commodity USB instrument, not custom hardware). TradeProof has an optional Quest VR training module, but its core flow (photo, NEC check, portfolio) is phone and web. Bloom's WHOOP link is an optional API integration. Detour and CalTrack ran models on an NVIDIA DGX Spark for the Edge AI track, but they read no sensors and could run on any GPU host. Paper Cuts runs on an iPad or browser canvas with phones as controllers; the projector is optional. Fizz Buzz is comedic in tone, but it scores calm boundary-setting and gives coaching notes, so it was kept as a practice tool.
- **Borderline exclusions:** GridVeda runs on an on-site Jetson at the substation and is built around sensor readings. ZoneZero (software, Gemini vision) is named in Stanford Daily as an Ecopreneurship winner but has no Devpost winner badge, so it is not counted. Berkeley's "the-shepherd" appears in gallery scraping but its page shows no prize.
- **Mostly non-LLM AI keeps:** Mirage, ShotSpot, Morro and Paper Cuts use AI models (video generation, CLIP, GraphCast, a VLM and diffusion) as the core, but no LLM agent.
- Tags follow the product's core mechanic. Voice agents that *do tasks* (Hellocare, kiru, CareLoop, 311.ai) are ACTION-AGENT; voice agents built around *a population's ongoing care or support* (Bloom, CareLink, Lucid Voice, NextOp) are COMPANION-VOICE. Tools that help professionals decide and cite or verify (ContainOS, Detour, TradeProof, Aegis) are EXPERT-COPILOT.
